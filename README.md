# Español A2 Creator Demo v2

Public, no-login demonstration build for creator outreach.

## Goal
Show the full product concept and feature depth without shipping the full proprietary learning library.

## Included
- Dashboard with XP, level, streak and recommendations
- Lessons
- Study materials/reference library
- Vocabulary bank
- Custom vocabulary
- Flashcards
- Adaptive quick practice
- 30-second speed round
- Listening activities
- Weak-spot recommendations
- Short timed mock exam
- Progress analytics
- Achievements
- Study timetable
- Local-device progress

## Deliberately limited
Only a small sample of lessons, questions, words and listening prompts is present in the files.
There is no full production course database, no full DELE bank and no production backend.

## Deploy
Upload this folder to a separate static host/repository. Do NOT overwrite the full product until you have backed it up.

The public URL should point only to this demo build.
